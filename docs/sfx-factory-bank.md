# SFX factory bank

**16** one-shot presets in the **SFX** browser group (`sfx-*` IDs). Original designs for games and UI — not ripped from commercial titles.

## Usage

- Load a preset and tap a low key (e.g. **C2–C4**); release quickly for the envelope shape.
- Most route **Keyboard → SID 1** with arps off. **Explosion Boom** and **Teleport Spark** use **Layer** so all three engine cards contribute.
- Pitch envelopes (Laser, Coin, Power Up, etc.) need a single note-on; hold longer only when the patch has sustain (siren, engine rev).
